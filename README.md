# 🐰 제니의 영어나라 (Jenny's English Land)

하얀 토끼 **제니**가 만 3세 아이에게 영어를 알려주는 아이패드용 학습 앱입니다.
설치 없이 Safari에서 열고 **홈 화면에 추가**하면 일반 앱처럼 전체 화면으로 실행됩니다. 인터넷이 없어도 학습할 수 있어요(영상은 인터넷 필요).

## 아이패드에 설치하기

1. 이 저장소를 GitHub Pages로 공개합니다 → 저장소 **Settings → Pages → Build and deployment**에서
   Source: `Deploy from a branch`, Branch: 이 앱이 있는 브랜치 / `(root)` 선택 → Save
2. 1–2분 뒤 표시되는 주소(`https://<아이디>.github.io/Eng-study/`)를 아이패드 **Safari**로 엽니다.
3. 공유 버튼(□↑) → **홈 화면에 추가** → 이제 홈 화면의 제니 아이콘으로 실행합니다.
4. 처음 실행하면 아이 이름(한글)과 영어로 부를 이름(예: Nahyun)을 입력합니다.

> 💡 아이패드 **설정 → 손쉬운 사용 → 말하기 콘텐츠 → 음성**에서 영어(미국) 고품질 음성(예: Samantha 향상된 음성)을 내려받으면 제니 목소리가 훨씬 자연스러워집니다.
> 💡 **설정 → 손쉬운 사용 → 사용법 유도(Guided Access)** 를 켜면 아이가 앱 밖으로 나가지 못하게 할 수 있어요.

## 학습 구성

| 단계 | 내용 | 기간 |
|---|---|---|
| **Day 0** · Hello, Jenny! | 제니 만나기, 인사 표현 | 1일 |
| **Stage 1** · ABC Land | 알파벳 A–Z: 이름·소리(파닉스)·단어 3개·따라쓰기·게임, 5글자마다 복습 | 32일 |
| **Stage 2** · Word Forest | 색깔, 숫자, 동물, 과일, 몸, 가족, 기분, 모양, 탈것, 음식, 옷, 날씨, 동작, 장난감, 자연, 바다, 반대말 | 17일 |
| **Stage 3** · Talking Town | I like ___, This is a ___, How are you?, ___ please, Where is ___?, How many?, I can ___! | 8일 |
| **Stage 4~** · Rainbow Review | 배운 단어 + 우리 단어로 매일 맞춤 복습 (끝없이 계속) | ∞ |

**하루 수업 흐름 (약 10분)**: 제니 소개 → 단어 카드(듣고 따라 말하기) → 따라쓰기/게임 → 보상 스티커 → **동화·영상 추천**(페파피그, 블루이, 그림책 읽어주기 등)

- **레벨**: 0부터 시작, 별을 모을수록 계속 올라갑니다 (레벨이 오를수록 필요한 별이 늘어남).
- **게임 4종**: 그림 찾기, 짝 맞추기, 풍선 터뜨리기(알파벳), 제니 밥 주기
- **맞춤 학습**: 아이가 자주 틀리거나 덜 본 단어, 부모님이 추가한 단어가 게임·복습에 더 자주 나옵니다.

## 부모님 메뉴 (홈 오른쪽 위 ⚙️, 간단한 덧셈으로 잠금)

- 학습 현황: 레벨, 별, 연속 학습일, 배운 단어 수, 최근 4주 달력, 학습 시간
- 진도 관리: 원하는 Day로 이동, "하루에 새 수업 1개만" 설정
- **요일별 활동 계획**: 알파벳·따라쓰기·게임·우리 단어·복습·노래·동화를 요일마다 켜고 끄기 → 홈에 "오늘!" 표시
- 하루 학습 시간 제한(시간이 되면 제니가 "쉬는 시간"을 알려줌), 말하기 속도, 목소리 선택
- **우리 단어**: 아이가 좋아하는 물건·가족을 영어 단어로 추가 (사진 촬영 가능)
- **즐겨찾기 영상**: 유튜브 링크를 붙여넣으면 앱 안에서 바로 재생, 수업 후 추천에 먼저 표시
- 백업 저장/불러오기 (기록은 이 아이패드에만 저장되므로 가끔 백업 권장)

## 내용 추가하기

모든 학습 데이터는 [`js/data.js`](js/data.js) 한 파일에 있습니다.
- 새 주제 단어: `THEMES`에 항목 추가 → 커리큘럼에 자동으로 붙습니다.
- 새 문장 패턴: `SENTENCES`에 항목 추가
- 추천 영상: `VIDEOS`의 `songs`, `stories` 목록 수정

수정 후에는 `sw.js`의 `CACHE` 이름 숫자를 올리면(예: `v2`) 아이패드에 새 버전이 확실히 반영됩니다.

## 파일 구조

```
index.html            앱 진입점
css/style.css         디자인 (아이패드 12.9" 가로/세로 대응)
js/data.js            알파벳·단어·문장·커리큘럼·영상 데이터
js/app.js             화면, 음성(TTS), 게임, 부모님 메뉴
sw.js                 오프라인 캐시
manifest.webmanifest  홈 화면 앱 설정
icons/                앱 아이콘 (제니)
```
